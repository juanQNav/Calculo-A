# Calculus Integral — Interactive Solver

A Spanish-language static web app for practicing integral calculus with step-by-step solutions, reference formulas, strategies, and recommended videos.

**Live site:** [Open Calculus Integral](https://juanqnav.github.io/Calculo-A/)

> The GitHub repository is private, but the GitHub Pages site is public and accessible to anyone with the link.

## Features

- **18 worked exercises** across four exams, with interactive solution steps.
- **A 30-formula reference sheet** organized by topic.
- **Strategies and patterns** for recognizing integration techniques.
- **Quizzes** for practicing substitution choices.
- **Exercise-specific video recommendations** selected from the Calculus NotebookLM notebook and linked to YouTube.

## How to use

1. Open the [live site](https://juanqnav.github.io/Calculo-A/) or open `index.html` in a browser.
2. Select an exam and an exercise.
3. Step through the solution and open the related formulas or recommended videos as needed.

## Local development

No dependencies or build step are required. The app loads Tailwind CSS, MathJax 3, and Lucide from CDNs; an internet connection is required for those resources and for YouTube videos.

## Deployment

GitHub Pages publishes from the `main` branch and repository root (`/`) over HTTPS. The repository remains private; the published site is public.
